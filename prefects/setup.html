use API Setup's “Send message” to send yourself the hello_world template — it arrives on your phone.

Leave the template-name variables alone — the defaults match phase 5.

curl https://www.mathans.app/api/whatsapp/remind returns {"error":"Unauthorized"} — the route is alive and locked.
3Connect the webhook
text the test number from a verified phone (not the VHP's) — you should get the automated redirect reply ("…messages here aren't read, contact the enquiries number…"), which proves the whole round-trip. Once per sender per day; the VHP gets command help instead.
4Load contacts and roster 
curl -X POST https://www.mathans.app/api/whatsapp/contacts -H "Content-Type: application/json" -H "x-admin-secret: YOUR_ADMIN_SECRET" -d '{ "contacts": [ { "name": "Kingsley", "phone": "+85291234567", "role": "prefect", "optIn": true }, { "name": "Angelia",  "phone": "+85298765432", "role": "prefect", "optIn": true } ] }'
GET the same URL with the admin header — your list comes back with phones normalised to digits.
5Create the three templates

WhatsApp Manager → Message templates → Create template. Category Utility, language English (en), names and bodies exactly as in the README:

All three use named variables (pick "Name" as the variable type): {{name}}, {{gate}}, {{time}}, {{day}}, plus {{weather}} / {{notice}} — keep those exact names; the code fills them by name.

Rejected? Make the sample values look like a real message and resubmit — never change the variable order. The three hand-sent notice templates in notice-templates.md can wait; nothing in code depends on them.
6Dry-run the whole flow

One sitting, playing both roles, on the test number.

curl -H "x-admin-secret: YOUR_ADMIN_SECRET" "https://www.mathans.app/api/whatsapp/remind?date=2026-08-03"
curl -H "x-admin-secret: YOUR_ADMIN_SECRET" "https://www.mathans.app/api/whatsapp/morning"
7Go permanent

The temporary token dies daily — swap it before trusting the crons.

Real number, when ready to leave the 5-recipient test cage: the number must not be registered on the WhatsApp app — on that phone: Settings → Account → Delete account (“free the number”), wait a few minutes, then API Setup → Add phone number, verify by SMS, and update PHONE_NUMBER_ID in Vercel — the ID changes with the number. Tier 0 allows 250 unique recipients per rolling 24h; the whole board fits.
